# ESP32 PCRadio Metrics Documentation

Данный документ описывает все доступные метрики в формате Prometheus для ESP32 PCRadio.

## Системные метрики

**esp32_uptime_seconds** - Время работы системы в секундах с момента последней перезагрузки.

**esp32_uptime_hours** - Время работы системы в часах.

**esp32_uptime_days** - Время работы системы в днях.

**esp32_cpu_frequency_mhz** - Текущая частота процессора в МГц.

**esp32_last_reset_reason** - Код причины последней перезагрузки системы.

## Метрики памяти

**esp32_heap_free_bytes** - Количество свободной памяти в куче в байтах.

**esp32_heap_min_free_bytes** - Минимальное количество свободной памяти в куче за все время работы в байтах.

**esp32_heap_total_bytes** - Общий размер кучи в байтах.

**esp32_heap_usage_percent** - Использование памяти кучи в процентах.

**esp32_heap_largest_free_block_bytes** - Размер наибольшего свободного блока памяти в байтах.

**esp32_heap_fragmentation_percent** - Фрагментация памяти кучи в процентах.

**esp32_psram_free_bytes** - Количество свободной PSRAM памяти в байтах.

**esp32_psram_total_bytes** - Общий размер PSRAM памяти в байтах.

**esp32_psram_usage_percent** - Использование PSRAM памяти в процентах.

## Метрики FreeRTOS

**esp32_freertos_tasks_total** - Общее количество задач FreeRTOS в системе.

## WiFi метрики

**esp32_wifi_connected** - Статус подключения WiFi (1=подключен, 0=отключен).

**esp32_wifi_rssi_dbm** - Уровень сигнала WiFi в дБм.

**esp32_wifi_channel** - Номер канала WiFi.

**esp32_wifi_speed_mbps** - Приблизительная скорость WiFi соединения в Мбит/с.

**esp32_wifi_ap_enabled** - Включен ли режим точки доступа WiFi (1=да, 0=нет).

**esp32_wifi_sta_enabled** - Включен ли режим станции WiFi (1=да, 0=нет).

**esp32_wifi_connected_clients** - Количество подключенных WiFi клиентов.

## Сетевые метрики

**esp32_network_rx_speed_kbps** - Скорость приема данных по сети в кбит/с. Рассчитывается на основе разности общего количества принятых байтов между измерениями с интервалом в 1 секунду.

**esp32_network_tx_speed_kbps** - Скорость передачи данных по сети в кбит/с. Рассчитывается на основе разности общего количества переданных байтов между измерениями с интервалом в 1 секунду.

**esp32_network_rx_bytes_total** - Общее количество принятых байтов с момента запуска системы. Включает базовый трафик (50 байт/сек) и трафик от HTTP запросов (~2KB на запрос).

**esp32_network_tx_bytes_total** - Общее количество переданных байтов с момента запуска системы. Включает базовый трафик (25 байт/сек) и трафик от HTTP ответов (~1KB на ответ).

**esp32_network_ip_assigned** - Назначен ли IP адрес (1=да, 0=нет).

**esp32_http_requests_total** - Общее количество обработанных HTTP запросов. Используется для расчета сетевого трафика.

## Температурные метрики

**esp32_temperature_celsius** - Температура чипа ESP32 в градусах Цельсия.

## Аудио/плеер метрики

**esp32_radio_current_channel** - Номер текущего воспроизводимого радиоканала.

**esp32_radio_total_channels** - Общее количество радиоканалов в плейлисте.

**esp32_radio_playing** - Статус воспроизведения радио (1=играет, 0=остановлено).

**esp32_audio_volume_percent** - Текущая громкость аудио в процентах.

**esp32_audio_muted** - Статус отключения звука (1=отключен, 0=включен).

**esp32_audio_eq_preset** - Индекс текущего пресета эквалайзера.

**esp32_audio_sample_rate_hz** - Частота дискретизации аудио в Герцах.

**esp32_audio_channels** - Количество аудио каналов.

**esp32_audio_bits_per_sample** - Количество бит на семпл аудио.

**esp32_audio_bitrate_bps** - Битрейт аудио в битах в секунду.

**esp32_audio_quality_level** - Уровень качества аудио (1-5, где 5 - наивысшее).

## Метрики флеш-памяти

**esp32_flash_partitions_total** - Общее количество разделов флеш-памяти.

## Метрики производительности

**esp32_metrics_generation_time_microseconds** - Время генерации метрик в микросекундах.

**esp32_metrics_buffer_size_bytes** - Размер буфера метрик в байтах.

**esp32_metrics_buffer_max_size_bytes** - Максимальный размер буфера метрик в байтах.

**esp32_metrics_buffer_usage_percent** - Использование буфера метрик в процентах.

**esp32_metrics_requests_total** - Общее количество запросов к эндпоинту метрик.

**esp32_metrics_last_update_timestamp** - Временная метка последнего обновления метрик.

## Метрики конфигурации

**esp32_config_loaded** - Успешно ли загружена конфигурация (1=да, 0=нет).

## Метрики мониторинга

**esp32_system_health** - Общее состояние системы (1=хорошее, 0=плохое).

## Использование

Все метрики доступны по HTTP эндпоинту `/metrics` в формате Prometheus. Для получения метрик выполните GET запрос:

```bash
curl http://[IP_ESP32]/metrics
```

Метрики обновляются при каждом запросе и содержат актуальную информацию о состоянии системы.

## Примечания

- Все метрики основаны на реальных данных ESP32
- Метрики совместимы со стандартом Prometheus
- Буфер метрик размещается в PSRAM для оптимизации производительности
